# 日常经营所 · Daily Ops

把一个模糊的任务，变成**今天就能动手的下一步**：拆解、估时、排进日历、执行、复盘校准。

- 手机优先的 PWA：安卓 / iPhone 都能「添加到主屏幕」，全屏、离线运行，不用上架商店。
- **本地优先**：任务、计划、复盘全部存在设备的 IndexedDB 里，没有账号、没有后端、没有遥测。
- **拆解不靠 API**：内置 12 类任务模板 + 通用兜底 + 计划质检，离线可用、零 token。
- AI 是可选增强：网页版 DeepSeek 手动复制粘贴（免费），或自填 API Key 直连。

## 能做什么

| 模块 | 说明 |
| --- | --- |
| 记录 | 自然语言快速添加，自动识别「周五前」「明天」「2 小时」「半小时」等 |
| 拆解 | 按写作、学习、编程、求职、活动、旅行、搬家、健康、财务、创意、采购等模板生成步骤 |
| 步骤质量 | 每步都有产出物、验收标准、第一件事、常见坑；过长的步骤自动拆段 |
| 质检 | 自动指出没有产出物、验收标准、第一步动作，或排不进截止时间的计划 |
| 排程 | 按截止 → 重要度 → 依赖顺序，排进你的每日容量；单块 ≤90 分钟，预留 20%–30% 缓冲 |
| 复习 | 学习类任务自动插入 +1 / +3 / +7 天的间隔复习 |
| 修正 | 步骤可增删改、上下移动、改估时；每次生成/大改保留历史版本，可切回 |
| 头脑风暴 | 按「目标 / 障碍预演 / 取舍 / 下一步」提问，答案可一键转成行动项 |
| 复盘 | 本周完成率、估算偏差、引导式问题；完成时填实际用时，系统自动校准你的估时 |
| 数据 | 一键导出 JSON 备份，支持合并/覆盖导入；所有数据只在本机 |

## 本地开发

要求：Node.js 20.19+（开发时使用 Node 24）。

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/
npm run preview    # 预览构建产物（配合 --base /daily-ops/）
npm test           # Vitest：引擎、排程、质检、快速解析
```

> 在受限的 Windows 沙箱里跑 Vite 时，可能需要
> `NODE_OPTIONS=--require=./scripts/sandbox-noexec.cjs`（该脚本只拦截 Vite 启动时的 `net use` 探测）。
> 正常桌面环境不需要。

## 部署到 GitHub Pages

构建产物默认使用 `/daily-ops/` 作为 base（仓库名 `daily-ops`）。仓库是公开的，只包含代码与构建产物，**不包含你的任务数据**。

1. 仓库 `main` 分支根目录放 `dist/` 里的内容（`index.html`、`assets/`、`icons/`、`manifest.webmanifest`、`sw.js` 等）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
3. 打开 `https://<用户名>.github.io/daily-ops/`。

如果仓库名不同，把 `vite.config.ts` 里的 `base` 与 manifest 的 `start_url` / `scope` 改成对应路径后重新构建。

## 装到手机上

- **iPhone / iPad**：用 Safari 打开线上地址 → 分享 → 添加到主屏幕。
- **安卓**：用 Chrome / Edge 打开 → 菜单 → 安装应用 / 添加到主屏幕。

装好后可以全屏、断网使用；更新会在下次打开时自动生效。

## AI 增强（可选）

1. **本地引擎（默认）**：完全离线，零 token。模板 + PERT 估时 + 排程 + 质检。
2. **网页版 DeepSeek（免费）**：任务详情 →「AI 再拆」→ 复制提示词 → 粘到 chat.deepseek.com → 把返回的 JSON 粘回来 → 解析、预览、应用。
   - 不自动登录、不抓取网页，只使用你手动复制的内容。
3. **API 直连**：设置里填 base URL、模型、Key（只存本机）。浏览器可能被服务端 CORS 拦截，失败时用第 2 种方式。

AI 结果始终是草稿：先预览，再决定是否替换；旧计划保留在历史里。

## 计划方法

- **三点估算（PERT）**：`(乐观 + 4×最可能 + 悲观) / 6`，再乘你在这类任务上的校准系数。
- **缓冲**：每日容量先扣掉 20%–30%，留给路上、等人、返工。
- **时间块**：单块不超过 90 分钟；深度步骤优先进「黄金时段」，超过容量不会硬塞，而是给排不下的警告。
- **依赖链**：步骤按顺序串依赖，排程时不会把「第二步」排在「第一步」之前。
- **间隔复习**：学习类任务自动补 +1 / +3 / +7 天复习块。
- **校准闭环**：完成时填实际用时，按任务类型做指数平滑，估时会越来越贴近你的真实节奏。

## 技术栈与结构

Vite 8 · React 19 · TypeScript · Tailwind CSS 4 · Dexie（IndexedDB）· Zod · date-fns · lucide-react · vite-plugin-pwa

```
src/
  app/          AppContext（设置、toast、记录弹窗）
  components/   Shell、TaskCard、步骤编辑器、AI 面板、头脑风暴
  domain/       类型与 Zod、12 类模板、拆解/估时/排程/质检/校准、快速解析、AI
  db/           Dexie schema、数据仓库、导入导出
  pages/        今天 / 任务 / 计划工作室 / 日历 / 复盘 / 设置
tests/          引擎与排程单测
scripts/        图标生成、视觉冒烟脚本、受限沙箱辅助
```

## 已知限制

- PWA 没有后台推送提醒（无后端）；到期用日期颜色和应用内高亮提醒。
- 没有云同步：换设备请用导出/导入；iOS 长期不打开可能清理站点数据，建议每两周导出一次。
- 数据只在本机，浏览器清缓存/换浏览器会看不到旧数据。
- GitHub Pages 需要公开仓库；任务内容不会进仓库。

## 隐私

默认不向任何服务器发送数据。只有你主动使用 AI（粘贴或 API）时，任务文本才会进入对应服务。
