# 日常经营所 · Daily Ops

一个**安静、手机优先**的任务速记与计划工具：记下、贴张截图、写目的和过程、排进日程。

- 4 个页面：**今天 / 日程 / 全部 / 我的**。
- 打开就是输入框：**文字 + 截图/照片**，来不及写字就只贴图。
- 任务只做手动结构：**目的** + **过程一/二/三…**，不自动拆解，也不调 AI。
- 日程是可视化周视图/日视图/任务视图：桌面可拖动换时间、换天、改时长；手机点块精确改时间。
- 任务视图按任务列出全部过程、已排时间/重复规则，不再有单独的长“未排期”列表。
- 规则排期：每天 / 工作日 / 周末 / 自定义星期，或指定某几天；选好日期范围和每天时间段，先预览再排入。
- 重复安排：同一个过程可在这些天重复（如每天 19:00）；单次块可一键改成每天重复。
- 手动排过的过程会**锁定**，自动排期不会覆盖它。
- 数据只存本机（IndexedDB），无账号、无后端、无遥测；可导出 JSON 备份（含图片和重复规则）。

```

       记点什么，或贴张截图…             📷
今天 1
   [截图] 交季度报告   下一步：对齐读者…  0/6

    健身
```

底部：今天 / 日程 / 全部 / 我的。任务详情只有：目的、过程、图片；排期 / 按规则安排 / 编辑 / 完成 / 删除在「⋯」里。

## 功能

| 模块 | 说明 |
| --- | --- |
| 速记 | 自然语言识别「周五前」「明天」「2 小时」；可只贴图，标题自动生成 |
| 图片 | 相册多选、手机拍照、直接粘贴；自动压缩并生成缩略图；全屏查看/保存/删除 |
| 任务结构 | 手动写「目的」；「过程」下加过程一/二/三…；只填做什么和分钟，不自动生成、不调 AI |
| 排期 | 先预览「哪天几点排几个过程」，可今天/明天开始；一键写入，支持清空 |
| 日程 | 周 / 日 / 任务三视图；7 天时间轴、拖动、改时间、改时长、移出日程、撤销 |
| 规则排期 | 每天/工作日/周末/自定义星期，或指定日期；范围 + 每天时间段；按过程依次排、同一过程重复 |
| 重复 | 重复块按次勾选；今天页有「重复」区；可改规则/跳过这次/删除；单次块一键转每天重复 |
| 执行 | 今天页直接勾掉「下一步」；详情里逐条完成；全部完成可标记任务完成 |
| 数据 | 导入/导出（图片可选）、存储占用、清空 |

## 图片怎么存

- 单次最多 6 张，单任务最多 12 张，单张原图 ≤15MB。
- 浏览器内压缩：最长边 1600px，WebP 0.85（失败回退 JPEG）；缩略图 400px。
- 存在 Dexie `attachments` 表（Blob + 缩略图），列表只按需加载 40px 缩略图。
- 删除任务会一并删除图片；导出时图片以 base64 写入 JSON，导入时还原。
- 浏览器可能清理站点数据，建议每两周导出一次备份。

## 排期与手动调整

- 自动排期：截止优先 → 重要度 → 依赖顺序；每天容量、25% 缓冲、单块 ≤90 分钟。
- 任务视图：按任务分组，显示每个过程的分钟、已排时间、重复进度、未排状态；可直接单次安排或按规则安排。
- 规则排期：
  - **按过程排**：把未排过程依次摊到选中的星期/日期；可选「每次一个过程」或「尽量排满」，过程间留 10 分钟；冲突自动跳过，剩余过程会提示。
  - **重复做**：选一个过程，按每天/工作日/周末/自定义星期或指定日期重复；每次占用选定时间段。单过程任务默认就是重复。
  - 日期范围最多 90 天，指定日期最多 30 天；先看逐日预览再应用。
- 单次块可转重复：点块 →「改成每天/每周重复」；任务视图也会提示「改成每天重复」。转换后原单次块会移除，只保留重复规则。
- 重复块：虚线 + ⟳ 标记，不可拖动；点开可完成这次、修改规则、跳过这次、删除重复。
- 有重复规则的过程不再参与自动排期，且重复块会作为忙块被其他排期避让。
- 桌面周视图：拖动块换时间/换天，拖底部改时长，吸附 10 分钟；冲突会拒绝，改完可撤销。
- 手机日视图：点块 →「改时间 / 改时长」，日期 + 开始时间 + 时长精确设置。
- 任何手动调整都会把过程标记为**锁定**；重新自动排期会保留锁定块，其余绕开。
- 冲突规则：同一时间只允许一个块；手动可以超出每日容量，但会标红。
- 溢出/跨天：时间限制在 00:00–24:00，不跨天。

## 开发

要求 Node.js 20.19+（开发使用 Node 24）。

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/
npm test           # 48 个单测：估计、手动过程、排期、锁步、冲突、规则日期/分配、重复、图片仓库、导入导出
npm run preview    # 本地预览构建产物
```

在受限 Windows 沙箱里跑 Vite 时需要：

```bash
NODE_OPTIONS=--require=./scripts/sandbox-noexec.cjs npm run dev
```

（正常桌面环境不需要这个 helper。）

## 部署到 GitHub Pages

构建 base 固定为 `/daily-ops/`（仓库名 `daily-ops`）：

1. 把 `dist/` 内容放到仓库 `main` 分支根目录。
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
3. 打开 `https://<用户名>.github.io/daily-ops/`。

仓库只包含站点文件；你的任务和图片不会上传。仓库名不同时，改 `vite.config.ts` 的 `base` 与 manifest 的 `start_url` / `scope`。

## 装到手机

- iPhone/iPad：Safari 打开 → 分享 → 添加到主屏幕。
- 安卓：Chrome/Edge 打开 → 菜单 → 安装应用 / 添加到主屏幕。

安装后全屏、离线可用；新版本在下次打开时自动更新，数据不动。

## 数据与兼容

- Dexie v4：计划增加 `purpose`；旧的自动拆解/AI/头脑风暴数据与图片原样保留，只是不再有自动拆解和 AI 入口。
- v4 升级会清空旧设置里的 AI API Key；旧计划里的过程会显示成 `过程一/二…`，可自行删减。
- 旧地址 `/calendar` 跳到 `/schedule`；`/review` 回首页；原日程弹层升级为可视化页面。
- 导出 schemaVersion=4（含 `purpose` 和 `routines`）；可导入 v1/v2/v3 旧备份。

## 已知限制

- 没有云同步：手机和电脑各存各的，用导出/导入搬运。
- PWA 没有后台推送提醒。
- 排期不做手指拖拽（手机用改时间面板）；桌面拖动只支持鼠标；重复块不可拖动，改规则请点开块。
- 重复规则按单个过程创建，同一任务多个重复过程需要分别创建（会检查时间段重叠）。
- 任务结构和过程完全手动；没有自动模板、AI 拆解或 AI 问答。
- iOS 长期不打开可能清理站点数据，记得备份。
