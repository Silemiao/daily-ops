# 日常经营所 · Daily Ops

一个**安静、手机优先**的任务速记与计划工具：记下、贴张截图、写目的和过程、把整件事或某个过程排进日程。

- 4 个页面：**今天 / 日程 / 全部 / 我的**。
- 打开就能记：**文字 + 截图/照片 + 语音**。
- 任务只做手动结构：**目的** + **过程一/二/三…**，不自动拆解，也不调 AI。
- 任务本身可以排“整件事”，子过程也可以单独排；点任务块能看到全部过程，点过程块能看到所属任务和其他过程。
- 语音可以直接记任务，也可以对已有任务说“明天下午三点”“这两周每天”“从 20 号到 30 号的每天下午”。
- 日程有周 / 日 / 任务三视图：桌面拖动换时间、换天、改时长；手机点块精确改。
- 规则排期：每天 / 工作日 / 周末 / 自定义星期，或指定日期；选好范围和时间段，先预览再排入。
- 手动排过的过程会**锁定**，自动排期不会覆盖它。
- 数据只存本机（IndexedDB），无账号、无后端、无遥测；可导出 JSON 备份（含图片和重复规则）。
- 视觉是克制的瑞典田园风：亚麻纸、鼠尾草绿、法鲁红、奶油黄、野花线稿。

## 功能

| 模块 | 说明 |
| --- | --- |
| 速记 | 自然语言识别「周五前」「明天」「2 小时」；可只贴图，标题自动生成 |
| 语音记任务 | 点麦克风说“明天下午三点写季度报告”，保存任务时一并排好 |
| 语音排任务 | 任务页 / 日程页点麦克风；支持单日、范围、每天、每周几、工作日、周末、上午/下午/晚上、中文数字 |
| 图片 | 相册多选、手机拍照、直接粘贴；自动压缩并生成缩略图；全屏查看/保存/删除 |
| 任务结构 | 手动写「目的」；「过程」下加过程一/二/三…；只填做什么和分钟 |
| 整件事排期 | 零过程任务也能排；可单次或按规则重复；默认时长取任务预计，最长 240 分钟 |
| 过程排期 | 单次时间块、按规则依次排、同一过程重复；任务块和过程块可同时存在 |
| 层级查看 | 点任务块看全部过程及各自时间；点过程块看父任务、同任务兄弟过程和各自时间 |
| 日程 | 周 / 日 / 任务三视图；7 天时间轴、拖动、改时间、改时长、移出日程、撤销 |
| 规则排期 | 每天/工作日/周末/自定义星期，或指定日期；范围 + 每天时间段；按过程依次排、同一过程重复 |
| 重复 | 重复块按次勾选；今天页有「重复」区；可改规则/跳过这次/删除；单次块一键转重复 |
| 执行 | 今天页直接勾掉「下一步」；详情里逐条完成；全部完成可标记任务完成 |
| 数据 | 导入/导出（图片可选）、存储占用、清空 |

## 语音怎么用

入口：

- 今天页速记卡的麦克风，或顶部导航麦克风：**语音记一件事**。
- 任务页「安排」卡片里的「语音」：**对这件事说时间**。
- 日程页头部麦克风：**先选一件事，再说时间**；也可以直接说任务名做 best-effort 匹配。

可以直接说：

- `明天下午三点`
- `这两周每天`
- `从 11 月 20 号到 30 号的每天下午`
- `每周一三五晚上七点半`
- `工作日早上九点`
- `过程二明天下午三点`
- `周五前交报告`（只设截止，不排时间）

规则：

- “这两周”= 今天起 14 天；“每天”没有结束范围时默认 28 天，并受任务截止日限制。
- 没说时间时默认 09:00；说“下午/晚上/上午”按 14:00 / 19:00 / 09:00 起。
- 说“前/之前/截止”按截止处理，不占用日程。
- 说完会自动排好，并给撤销；解析不完整、任务不明确、时间冲突时不会硬排。
- 语音由浏览器/系统识别，**本应用不保存录音**；识别服务可能联网。
- 支持 Chrome / Edge / Android Chrome、Safari iOS 14.5+ 等；Firefox 不支持。
- 不支持时仍可用文字 + 键盘上的麦克风听写，手动排期不受影响。

## 图片怎么存

- 单次最多 6 张，单任务最多 12 张，单张原图 ≤15MB。
- 浏览器内压缩：最长边 1600px，WebP 0.85（失败回退 JPEG）；缩略图 400px。
- 存在 Dexie `attachments` 表（Blob + 缩略图），列表只按需加载 44px 缩略图。
- 删除任务会一并删除图片；导出时图片以 base64 写入 JSON，导入时还原。
- 浏览器可能清理站点数据，建议每两周导出一次备份。

## 排期与手动调整

- 整件事：`Task.schedule` 存单次块；`Routine.targetType='task'` 存重复。单次和重复互斥。
- 过程：`Plan.steps` 的 `scheduledDate/startMin/endMin` 存单次；`Routine.targetType='step'` 存重复。
- 自动排期：截止优先 → 重要度 → 依赖顺序；每天容量、25% 缓冲、单块 ≤90 分钟；任务块和任务重复会作为忙块避开。
- 任务视图：按任务分组，顶部“整件事”一行，下面每个过程的分钟、已排时间、重复进度、未排状态。
- 规则排期：
  - **按过程排**：把未排过程依次摊到选中的星期/日期；可选「每次一个过程」或「尽量排满」，过程间留 10 分钟；冲突自动跳过，剩余过程会提示。
  - **重复做**：选一个过程或整件事，按每天/工作日/周末/自定义星期或指定日期重复；每次占用选定时间段。
  - 日期范围最多 90 天，指定日期最多 30 天；先看逐日预览再应用。
- 单次块可转重复：点块 →「改成每天/每周重复」；转换后原单次块会移除。
- 重复块：虚线 + ⟳ 标记，不可拖动；点开可完成这次、修改规则、跳过这次、删除重复。
- 有重复规则的过程不再参与自动排期，且重复块会作为忙块被其他排期避让。
- 任务块和它自己的过程块允许重叠，日历按 lane 分栏显示；和其他任务冲突会拒绝。
- 桌面周视图：拖动块换时间/换天，拖底部改时长，吸附 10 分钟；冲突会拒绝，改完可撤销。
- 手机日视图：点块 →「改时间 / 改时长」，日期 + 开始时间 + 时长精确设置。
- 任何手动调整都会把过程标记为**锁定**；重新自动排期会保留锁定块，其余绕开。
- 时间限制在 00:00–24:00，不跨天。

## 开发

要求 Node.js 20.19+（开发使用 Node 24）。

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/
npm test           # 77 个单测：解析、排期、任务块、重复、图片、导入导出
npm run preview    # 本地预览构建产物
```

在受限 Windows 沙箱里跑 Vite / 测试时需要：

```bash
NODE_OPTIONS=--require=./scripts/sandbox-noexec.cjs npm run dev
```

（正常桌面环境不需要这个 helper。）

本地预览构建产物必须带 base，否则 assets 会 404：

```bash
npm run preview -- --host 127.0.0.1 --port 4173 --base /daily-ops/
```

## 部署到 GitHub Pages

构建 base 固定为 `/daily-ops/`（仓库名 `daily-ops`）：

1. 把 `dist/` 内容放到仓库 `main` 分支根目录。
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
3. 打开 `https://<用户名>.github.io/daily-ops/`。

仓库只包含站点文件；你的任务和图片不会上传。仓库名不同时，改 `vite.config.ts` 的 `base` 与 manifest 的 `start_url` / `scope`。

## 装到手机

- iPhone/iPad：Safari 打开 → 分享 → 添加到主屏幕。
- 安卓：Chrome/Edge 打开 → 菜单 → 安装应用 / 添加到主屏幕。

安装后全屏、离线可用；新版本在下次打开时自动更新，数据不动。

### iPhone / iPad 添加到主屏幕

- 用 **Safari** 打开 `https://silemiao.github.io/daily-ops/`，点分享 →「添加到主屏幕」。
- 如果桌面图标打开白屏，先在 Safari 里打开同一地址，停留几秒后刷新一次，再回到图标打开；第一次可能还是旧界面，关掉再开一次即可更新。
- **不要直接删除图标**：iOS 删除主屏幕 Web App 时可能连本地数据一起删除。先在 App 内「我的 → 导出备份」，再考虑移除重装。
- 新版发布后会自动保留旧版 JS/CSS 资源，旧图标不会因为资源 404 而白屏。
- 语音在 iOS 主屏幕 Web App 里可能不可用；可用 Safari 打开，或点输入框用键盘上的麦克风。

## 数据与兼容

- Dexie v5：任务增加 `schedule`，重复规则增加 `targetType`；旧任务/重复规则自动补默认值。
- 导出 schemaVersion=5（含任务块和任务重复）；可导入 v1–v4 旧备份。
- 旧地址 `/calendar` 跳到 `/schedule`；`/review` 回首页。
- 旧版自动拆解/AI/头脑风暴数据不再有入口，但旧备份仍可导入。

## 已知限制

- 没有云同步：手机和电脑各存各的，用导出/导入搬运。
- PWA 没有后台推送提醒。
- 语音依赖浏览器/系统识别；离线时可能不可用，本应用不保存音频。
- 任务块和过程块同时存在时会重复占用容量，界面会显示两块；这是“整件事 + 细节”的取舍。
- 手机周视图需要横向滚动（日视图更适合手机）。
- 任务结构和过程完全手动；没有自动模板、AI 拆解或 AI 问答。
- iOS 长期不打开可能清理站点数据，记得备份。
